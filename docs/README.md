## 文档总览

本目录包含 NetPilot eNSP AI 网络助手（`netpilot-ai`）的产品与技术文档，建议配合项目根目录下的 `README.md` 一起阅读。

| 文档 | 内容 |
| --- | --- |
| `INTRODUCTION.md` | 产品简介与典型使用场景 |
| `USER_GUIDE.md` | **端到端使用说明**（环境准备 → 添加设备 → 解析执行 → 拓扑 → 诊断） |
| `FEATURES.md` | 核心特性列表（自然语言解析、命令注释、设备扫描、拓扑、诊断等） |
| `ARCHITECTURE.md` | 高层架构、关键流程说明与 Mermaid 架构图 |
| `STRUCTURE.md` | 项目目录结构、各目录职责与关键 API 速查 |
| `CHANGELOG.md` | **修订说明与新增功能**（改动清单、问题根因、验证结果） |
| `GITHUB_GUIDE.md` | **GitHub Fork 与代码上传指南**（Fork → 改名 → 提交 → 同步上游） |
| `PRODUCT_OVERVIEW.md` | 以上文档的索引入口，方便跳转 |

### 推荐阅读路径

- **初次接触**：根目录 `README.md` → `INTRODUCTION.md` → `USER_GUIDE.md`
- **只想用起来**：`USER_GUIDE.md`
- **想了解实现**：`ARCHITECTURE.md` → `STRUCTURE.md`
- **想确认能力边界**：`FEATURES.md`
- **想上传/发布代码**：`GITHUB_GUIDE.md`

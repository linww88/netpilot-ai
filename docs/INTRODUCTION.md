## 产品简介

**NetPilot eNSP AI 网络助手**（仓库名：`netpilot-ai`）是面向华为 eNSP 实验环境的智能网络助手，基于开源项目 **eNSP AI Assistant** 二次开发而来。
它可以理解你的自然语言配置意图，自动生成华为 VRP 配置命令，完成设备自动发现、连接、批量下发、拓扑发现和故障诊断，并通过 Streamlit Web 界面提供可视化交互。

### 典型使用场景

- **网络课程 / 实验室**：快速搭建、修改 eNSP 拓扑配置。
- **日常练习**：用自然语言驱动 VRP 配置，减少命令记忆成本。
- **批量运维**：一键扫描发现本机 eNSP 设备，读取主机名自动命名，批量下发与巡检。
- **故障排查**：自动采集多设备信息，让 AI 辅助分析根因并给出修复建议。

### 核心能力一句话概览

| 能力 | 说明 |
| --- | --- |
| 自然语言解析 | 一句中文 → 结构化配置任务（调用大模型） |
| 命令预览 | 同时展示 JSON 与带中文注释的华为 VRP 命令（本地生成） |
| 设备发现 | 扫描 2000–2100 端口，识别设备并读取主机名自动命名 |
| 配置下发 | 按设备分组执行，自动解析设备名，健壮处理 eNSP 分页与配置模式 |
| 拓扑发现 | 基于 LLDP / 接口信息构建并可视化网络拓扑 |
| 故障诊断 | 并发采集路由表与接口状态，AI 给出根因与修复命令 |

### 快速开始

```bash
pip install -r requirements.txt
cp .env.example .env          # 填入 DEEPSEEK_API_KEY
streamlit run src/main.py
```

详细操作步骤请参阅 `docs/USER_GUIDE.md`。
